# MEASURE READ THE FIRST TIME--S. 1752

```
                  MEASURE READ THE FIRST TIME--S. 1752

  Mr. REID. Mr. President, I am told that S. 1752 is due for its first 
reading.
  The PRESIDING OFFICER. The clerk will read the bill by title for the 
first time.
  The legislative clerk read as follows:

       A bill (S. 1752) to reform procedures for determinations to 
     proceed to trial by court-martial for certain offenses under 
     the Uniform Code of Military Justice, and for other purposes.

  Mr. REID. I now ask for a second reading but object to my own 
request.
  The PRESIDING OFFICER. Objection having been heard, the bill will be 
read for a second time on the next legislative day.

                          ____________________
```
