# MEASURE READ THE FIRST TIME--S. 1963

**Speaking:** Durbin, Richard J. (D000563) [D-IL]

**Measures:** S. 1963

```
                  MEASURE READ THE FIRST TIME--S. 1963

  Mr. DURBIN. I understand S. 1963 introduced earlier today by Senator 
Pryor is at the desk, and I ask for its first reading.

       A bill (S. 1963) to repeal section 403 of the Bipartisan
```
